# Cover LeetCode 学習プラン（2段階アプローチ）

> 「Cover」= まずデータ構造とアルゴリズムを **広く覆う**（全体地図を作る）。詳細暗記は後回し。

## 概要

AI が手書きコードを生成できる時代において、最も重要なのは「**データ構造とアルゴリズムについて議論できる**」こと。
細かい実装の暗記より、概念の地図と判断軸を先に手に入れる方が実務で効く。

そのため本プランは2段階で進める:

1. **第1段階: 大枠概観** — 細部の暗記には拘らず、全データ構造とアルゴリズムを「議論できる」レベルまで広く浅く触る
2. **第2段階: 手書き定着** — 第1段階で議論できる概念を、実際に自力実装できるレベルに引き上げる

第1段階を終えた時点で、AI解答のレビューや業務での技術判断はかなり可能になる。
第2段階は「面接で書ける」「自力で問題を解ける」を目指す上乗せ。

### 目標の段階定義

| ゴール | 達成段階 | 確認指標 |
|---|---|---|
| AIコードの計算量を判断できる | 第1段階で達成 | 「これは O(n²) ですね、Set 使えば O(n) になります」が言える |
| 適切なデータ構造を選択できる | 第1段階で達成 | 「Top-K なら Heap」「重複検出なら Set」が即答できる |
| 設計レビューで建設的に意見できる | 第1段階で達成 | パターン名で会話できる（DP / BFS / Two Pointers 等） |
| 面接でホワイトボード実装できる | 第2段階で達成 | Easy 自力実装 + Medium も時間かければ書ける |
| Medium を安定して自力で解ける | 第2段階で達成 | 制限時間内で正答 |

## 進め方

`/cover-leetcode` で次のステップを進める。

- 📖 / 🔍 / ⚖️: ファイル生成なし。Claude が概念やコードを提示し、ユーザーは口頭/文章で議論する。Claude がフィードバック。
- 🛠: TODO テンプレートを生成。ユーザーが自力実装。Claude がレビュー。
- 🧠: 間隔反復で過去ステップから新規問題を出題。

復習スケジュールは間隔反復（1日→3日→7日→14日→30日→卒業）。

### 第1段階の心構え

- 「分からない」と思ったらすぐ Claude に聞いて議論する。暗記しようとしない。
- 1ステップ30分目安。長引いても切り上げて次に進む。
- 「議論できる」「説明できる」が合格ライン。コードを書ける必要はない。

### 第2段階の心構え

- 1ステップ60分目安。時間内で書ききる練習も兼ねる。
- 詰まったら諦めて Claude に解答を聞き、翌日もう一度書き直す。
- 第1段階で築いた地図を頼りに、「何を書くべきか」は迷わない状態を活かす。
